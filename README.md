🐍 Snake Game (HTML Single File)
간단하고 직관적인 스네이크 게임(Snake Game) 입니다.
HTML + CSS + JavaScript 모두 하나의 파일에 포함되어 있으며,
브라우저에서 바로 실행할 수 있습니다.

✔️ 방향키로 조작
✔️ 점수 / 최고 점수(LocalStorage 저장)
✔️ 속도 증가 시스템
✔️ 시작/재시작 버튼
✔️ 반응형 UI


🖥️ 실행 방법

리포지토리를 다운로드 또는 클론합니다.
Shellgit clone https://github.com/yourname/snake-game-html.git더 많은 선 표시

프로젝트 폴더 내 snake.html 파일을 브라우저로 실행합니다.
별도 설치 없이 바로 플레이할 수 있습니다.


🎮 조작 방법

↑ : 위로 이동
↓ : 아래로 이동
← : 왼쪽으로 이동
→ : 오른쪽으로 이동


🧩 주요 기능
✔️ 단일 HTML 파일 구성
CSS, JS가 한 파일에 포함되어 있어 배포가 매우 간편합니다.
✔️ 최고 점수 저장(LocalStorage)
브라우저를 종료해도 최고 점수가 기록됩니다.
✔️ 난이도 증가
사과 5개 먹을 때마다 이동 속도가 1 증가합니다.
✔️ 180도 회전 방지
고전 스네이크와 동일하게 반대 방향으로 즉시 이동할 수 없습니다.
✔️ 반응형 인터페이스
캔버스 크기는 고정이지만 전체 레이아웃은 화면 크기에 따라 자연스럽게 조정됩니다.
